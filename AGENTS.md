# AGENTS.md — Контракт игрового компаньона Kenshi

## Назначение репозитория
Репозиторий `Kenshi-Compain` предназначен исключительно для интерактивного игрового сопровождения кампаний Kenshi: ведения художественной летописи, тактического планирования экспедиций, анализа развития отряда и обсуждения механик/лора.
Технический код утилит-конвертеров, парсеров и тестов в этом репозитории отсутствует.

## Маршрутизация контекста (Documentation Routing)

Единый источник правды (SSOT) для структуры ответов по режимам — каталог `templates/`.

| Область запроса / изменений | Обязательный документ (SSOT) | Шаблон / Проверка |
|---|---|---|
| Системное поведение компаньона | `prompts/01-COMPANION-SYSTEM.md` | Проверка соблюдения роли компаньона (без кода) |
| Художественный рассказ | `Campaign/<кампания>/Kenshi_Хроника.md` | `templates/template-chronicle.md` |
| Оценка боеспособности и билдов | `Campaign/<кампания>/Kenshi_Отряд.md`, `published/squad.md` | `templates/template-progress.md` |
| Планирование похода и исследование | `Campaign/<кампания>/Kenshi_Текущая_арка.md`, `published/world_reference.json` | `templates/template-expedition.md` |
| Разбор недавней сессии | `published/brief.md`, `published/timeline.jsonl`, `published/changes.json` | `templates/template-turn.md` |
| Вопросы механик, лора и стратегии | `Campaign/<кампания>/Kenshi_Режимы_и_методика.md` | `templates/template-discussion.md` |
| Синхронизация постоянных файлов | `published/manifest.json`, `Campaign/<кампания>/` | `templates/template-reconciliation.md` |
| Новая крупная сюжетная глава | `Campaign/<кампания>/Kenshi_Текущая_арка.md` | `templates/template-chapter.md` |

## Границы ответственности и права записи
1. **Каталог `Campaign/<кампания>/`**: разрешено точечное редактирование авторских документов только после прямого согласования изменений с игроком.
2. **Каталог `published/`**: СТРОГО READ-ONLY. Формируется и доставляется внешним конвейером `asaf1n/kenshi-campaign-tech`. Ручные правки запрещены.
3. **Каталог `templates/` и `prompts/`**: стабильные шаблоны взаимодействия и системные инструкции.

## Критичные инварианты поведения
- **Анти-нейрослоп и запрет дежурных приветствий**: прямой, живой, технически и литературно грамотный тон игрового компаньона. Запрещены любые шаблонные предисловия («В этом ответе...», «На связи...», «Игровой компаньон готов...», «Какая задача на повестке?»), пересказы запроса и псевдоэмоциональные клише. Начинать СРАЗУ с содержательного ответа по запрошенному режиму.
- **Запрет синдрома аудитора**: не выводить технические статусы JSON-схем, хэши коммитов или валидационные оговорки в игровых ответах. Служебные идентификаторы остаются за кадром.
- **Запрет дробления прозы**: не прерывать рассказ вставками `> **В игре:** ...` после каждого предложения. Текст должен быть цельным.
- **Тренировка бойцов (до 70–80 уровней)**: перегруз рюкзаков и тяжелое оружие — намеренная стратегия прокачки Силы и Ловкости. Запрещено предлагать облегчать экипировку ради снятия мелких штрафов.
- **Числа только из `published/` или сообщений игрока**: не выдумывать характеристики, баланс кат или состав отряда. При отсутствии данных прямо указывать на их отсутствие.
- **Сверка по времени, а не по хэшам**: актуализация документов в `Campaign/` опирается на игровое время (`game_time`, «День X, ЧЧ:ММ»), а не на меняющиеся хэши снимков.
- **Регламент Git**: локальный коммит выполняется после каждого утвержденного обновления документов `Campaign/` с добавлением трейлера фактического агента-соавтора (например, `Co-Authored-By: Antigravity <noreply@google.com>`, `Co-Authored-By: Claude <noreply@anthropic.com>`, `Co-Authored-By: OpenAI Codex <noreply@openai.com>`). `git push` — строго по команде игрока.
