## Действующие стратегические решения
- [x] **Тренировочный режим колонны**: перегруз рюкзаков рудой/железом до 70–80% для форсированной прокачки Силы и Стойкости до капа 75+. Мелкие штрафы к скорости хода приняты.
- [x] **Военная линия: «Белые латы»**: штурмовое подразделение тяжелого прорыва (Хот Лон, Сэто, Кан, Раненая Скво). Принята связка: Белая куртка с латами / Латы самурая + тяжелое оружие (Падающее солнце, Топпер, Палаш). - [x] **Союз с Шеками**: альянс с Каменным Эсатой (+88). Феникс передан шекам. Вражда со Святой Нацией (-100).
- [x] **Приоритет вооружения Мейто**: Крест паладина — Гриффин; Конеруб — Вечный Суньвынь; Бердыш — Мрачный Нил; Клинок ниндзя — Флик; Сабля с отверстием — Крошка Джон; запасная Доска изгнанника — вьючный бык.
