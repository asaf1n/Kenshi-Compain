# Хроники Хот Лон

Канонический источник прохождения — GitHub `main`. Две роли — игровой компаньон и летопись — читают общие материалы напрямую. Игровой `[итог]` публикует закрытый `S-YYYYMMDD-n.md` и необходимые изменения истории; летопись может самостоятельно консолидировать подтверждённую историю и развивать литературные материалы. `published/` формируется техническим конвейером и не редактируется вручную.

## История и статус

- [Единая Хронология](Kenshi_Хронология.md) — главы I–X, межглавье и реконструкция до **Day 132, 23:02**. **Закрытая граница: Day 130, 21:31.** При публикации новых сейвов эти границы не продвигаются автоматически.
- [Ретроспективный первоисточник дней 128–132](archive/sessions/RET-128-132.md) — сохраняется неизменным; не является исходной закрытой `S-...` сессией.
- [Архив будущих закрытых сессий](archive/sessions/) — `S-YYYYMMDD-n.md` формируются игровым `[итог]`, без создания фиктивных сессий для реконструкции.
- Исторические версии заменённых сводок (Канва, Хронология дней 1–130 и отдельная реконструкция дней 131–132) доступны в [Git по коммиту до консолидации](https://github.com/asaf1n/Kenshi-Compain/tree/e2f8918bd8dd1075685a6487dc06a3ad89f928ee/Campaign). Они не подменяют новую Хронологию.
