# Хроники сессий

Один файл на сессию: `S-YYYYMMDD-n.md` — хроника сессии, написанная по её выгрузке (`archive/sessions/S-YYYYMMDD-n.md`) в режиме `[хроника]` по руководству хрониста и шаблону `templates/template-chronicle.md`.

Выгрузка сессии — основа и источник фактов; хроника — художественный текст поверх неё. При расхождении прав выгрузка. Хроника может переписываться и расширяться; выгрузка остаётся без изменений. Главы повести собираются из хроник сессий по плану `archive/povest/README.md`.
