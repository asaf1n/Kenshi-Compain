# Выгрузки сессий

Один файл на сессию: `S-YYYYMMDD-n.md`. Формат — раздел «Выгрузка сессии» шаблона `templates/template-session.md`:

1. **Художественные тексты сессии** — все тексты, написанные в сессии, без изменений.
2. **Разбор сессии по решениям** — ход сессии, очищенный от форматирования чата и технических диалогов, с минимальной правкой формулировок и дословными словами игрока.
3. **Строка хронологии** — та же строка, что внесена в Канву.

Файл после записи не меняется. Уточнения к прошлым сессиям вносятся разделом «Исправления» следующей выгрузки.

Список сессий и их игровых интервалов — в `Kenshi_Канва.md`. Сессия, выгрузка которой ещё не перенесена в репозиторий, хранится в источниках проекта хроники под тем же идентификатором.
