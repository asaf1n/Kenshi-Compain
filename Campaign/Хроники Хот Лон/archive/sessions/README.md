# Выгрузки сессий (артефакты хроники сессий)

Один после проверки полноты и подтверждённого сохранения неизменяемый файл на каждую игровую сессию: `S-YYYYMMDD-n.md`. Формируется в режиме `[итог]` по шаблону `templates/template-session.md` и сразу служит готовой сессионной хроникой:

1. **Художественные вставки сессии** — все короткие лор-вступления (`[глава]`, `[этап]`) и сцены с блоками игровых событий (`[ход]`), написанные по ходу сессии, дословно без изменений.

2. **Разбор сессии по решениям (`D-nnnn`)** — структурированный ход обсуждения, дословные слова игрока, статус решения и фактический исход в игре.

3. **Строка хронологии** — краткая запись для `Kenshi_Канва.md`.

На основе закрытой хронологии дней 1–130 и артефактов `S-YYYYMMDD-n.md` в блокноте летописи (`Kenshi Compain. Летопись Hot Lon`) отдельным заданием пишется и расширяется полнообъёмная художественная повесть (`archive/povest/`).

Проверка полноты и контрольные точки — `docs/session-protocol.md`. Неполная выгрузка является черновиком, пока не восстановлены недостающие сцены/решения.
