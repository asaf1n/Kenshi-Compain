# Выгрузки сессий (артефакты хроники сессий)

Один после проверки полноты и подтверждённого сохранения неизменяемый файл на каждую игровую сессию: `S-YYYYMMDD-n.md`. Формируется и **непосредственно записывается игровым режимом `[итог]` в GitHub `main`** по шаблону `templates/template-session.md` одним коммитом с актуальной Канвой и необходимыми подтверждёнными правками. Команда `[итог]` разрешает запись. Готовый файл служит сессионной хроникой:

1. **Художественные вставки сессии** — все короткие лор-вступления (`[глава]`, `[этап]`) и сцены с блоками игровых событий (`[ход]`), написанные по ходу сессии, дословно без изменений.

2. **Разбор сессии по решениям (`D-nnnn`)** — структурированный ход обсуждения, дословные слова игрока, статус решения и фактический исход в игре.

3. **Строка хронологии** — краткая запись для `Kenshi_Канва.md`.

На основе закрытой хронологии дней 1–130, подтверждённых реконструкций и артефактов `S-YYYYMMDD-n.md` в независимом проекте летописи (`Kenshi Compain. Летопись Hot Lon`) **в любой момент** пишется и расширяется повесть (`archive/povest/`). Литературная обработка не нужна для закрытия игровой сессии и начала следующей.

Проверка полноты и контрольные точки — `docs/session-protocol.md`. Неполная выгрузка является черновиком, пока не восстановлены недостающие сцены/решения. Ошибка записи, отсутствие доступа к GitHub или конфликт версий не позволяют объявить сессию сохранённой; старые закрытые файлы не переписываются.
