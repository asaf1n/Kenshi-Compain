# Kenshi Compain — Игровой компаньон и летопись

Интерактивная среда сопровождения кампаний в Kenshi: тактическое планирование экспедиций, ведение художественной летописи, аналитика прогресса боевой колонны, исследование территорий и обсуждение игровых механик.

---

## Архитектура двух репозиториев

Для устранения смешивания контекста LLM между инженерной разработкой и игровым процессом архитектура разделена на два специализированных независимых репозитория:

```
┌──────────────────────────────────────────────┐
│        kenshi-campaign-tech                  │
│  (Технический конвертер данных)              │
│  • tools/, tests/, contracts/, raw/          │
│  • Парсинг сейвов, OCR скриншотов, валидация │
│  • Выпуск релиз-бандла published/            │
└──────────────────────┬───────────────────────┘
                       │
                       │ Автоматическая односторонняя доставка
                       ▼
┌──────────────────────────────────────────────┐
│        Kenshi-Compain                        │
│  (Игровое сопровождение и летопись)          │
│  • prompts/, templates/ (режимы диалога)     │
│  • Campaign/ (авторские летописи и билды)    │
│  • published/ (проверенный срез состояния)   │
└──────────────────────────────────────────────┘
```

| Параметр | `kenshi-campaign-tech` | `Kenshi-Compain` |
|---|---|---|
| **Назначение** | Инженерная утилита конвертации данных сейвов | Игровой аналитик, летописец, планировщик |
| **Исходный код** | Python (`tools/`, `tests/`, `contracts/`) | Отсутствует |
| **Авторские файлы** | Отсутствуют | `Campaign/<кампания>/` |
| **Данные игры** | Формирование, расчет геометрии и валидация | Получение готового пакета `published/` |
| **Роль модели** | Разработчик / QA-инженер Python | Игровой компаньон / Летописец / Стратег |

## Режимы взаимодействия

В диалоге с моделью используются короткие метки режимов. Каждая метка запускает структурированный шаблон:

1. **`[хроника]`** (`templates/template-chronicle.md`):
   Приключенческая прикладная проза по реальным событиям сейва. Атмосфера, характеры персонажей, напряжение, сцены и диалоги. Без перечисления JSON-полей и без навязчивых вставок `> **В игре:**`.
2. **`[прогресс]`** (`templates/template-progress.md`):
   Геймплейный тактический анализ боевой колонны (`Primaris`, `Secundus`, `Roaming`), проверка соответствия целевым билдам из `Kenshi_Отряд.md`, учет намеренной тренировки бойцов с перегрузом до 70–80 уровней.
3. **`[экспедиция]` / `[этап]`** (`templates/template-expedition.md`):
   Глубокое исследование регионов, климатические опасности (кислота, газ, лазеры), биомы, руины, противники, World States и варианты прохождения.
4. **`[ход]`** (`templates/template-turn.md`):
   Оперативный разбор недавней сессии: что произошло, кто кого несет на плече (`carrying`), чем заняты ремесленники на базах (`jobs.target_name`).
5. **`[обсуждение]`** (`templates/template-discussion.md`):
   Мозговой штурм по механикам Kenshi, взаимодействию модов, лору и альтернативным сценариям развития.
6. **`[сверка]`** (`templates/template-reconciliation.md`):
   Рабочая процедура синхронизации постоянных файлов в `Campaign/` по новой публикации. Задает 1–2 точечных вопроса только по спорным моментам и актуализирует канонические документы.
7. **`[глава]`** (`templates/template-chapter.md`):
   Открытие новой сюжетной арки: литературный пролог, политическая карта региона и 2–3 глобальных стратегических вектора.

## Источник данных и синхронизация

Релиз-бандл `published/` формируется во внешнем репозитории:
🔗 **Upstream:** [asaf1n/kenshi-campaign-tech/tree/main/published](https://github.com/asaf1n/kenshi-campaign-tech/tree/main/published)

При каждом обновлении игрового сохранения конвейер:
1. Извлекает состояние игры, выполняет геопривязку и валидацию данных.
2. Автоматически доставляет обновленный каталог `published/` в данный репозиторий `Kenshi-Compain`.
3. Модели в ChatGPT, Claude или Gemini используют свежие проверенные факты без прямого доступа к конвертеру.

## Подключение к ChatGPT / Claude / Gemini

- **ChatGPT Projects**: Создайте проект, подключите репозиторий `asaf1n/Kenshi-Compain` (или загрузите файлы `prompts/01-COMPANION-SYSTEM.md` и `Campaign/`). В Custom Instructions проекта укажите текст из `prompts/01-COMPANION-SYSTEM.md`.
- **Claude Projects**: Создайте Project, подключите локальную папку или загрузите `prompts/`, `templates/`, `Campaign/` и `published/`.
- **Gemini / Antigravity**: Модель автоматически подхватывает контракт из `AGENTS.md` и `GEMINI.md`.
