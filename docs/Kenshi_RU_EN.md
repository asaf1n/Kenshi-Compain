# Kenshi — общий русско-английский словарь

Сопоставления названий, терминов интерфейса и полей данных **для любой кампании Kenshi**. Документ не описывает посещённые места, состав отряда, игровые решения или историю конкретного прохождения.

Сопоставления собраны из игровых материалов и справочников; **не все строки независимо перепроверены по актуальным ресурсам локализации**. Неизвестную английскую пару не восстанавливай догадкой. Для спорного названия сверяй игровую локализацию, данные Kenshi или соответствующий общий справочник. Пользовательские имена и их варианты сохраняются только в материалах конкретной кампании.

## Коды и поля выгрузки

Подписи для текста вместо сырых значений `published/`. Подписи описательные: строки локализации игры здесь — только навыки и характеристики (раздел выше). Код, которого нет в таблице, описывается словами по смыслу, без вывода самого кода.

| Код или поле | Подпись в тексте |
|---|---|
| `ps:…` | Не выводится; только при совпадении имён — в скобках после имени |
| `Безымянные_N` | Не выводится; отряд называется именем, которое дал игрок |
| `in_region` | в регионе … |
| `in_location` | в тексте модели — с названием локации в нужном падеже («в городе»); в генерируемых материалах (карта, сводки) — «в локации: [название]» |
| `near_location` | в тексте модели — «в окрестностях поселения» (с расстоянием, если оно важно); в генерируемых материалах — «рядом с локацией: [название]» |
| `kind`: `town` / `village` / `outpost` / `ruins` | город / деревня / аванпост / руины |
| `kind`: `military` / `slave_camp` / `prison` / `poi` | военная база / лагерь рабов / тюрьма / особое место |
| `JOB_MEDIC` | лечит раненых |
| `JOB_REPAIR_ROBOT` | чинит скелетов и протезы |
| `BODYGUARD [имя]` | охраняет … |
| `STAY_CLOSE_TO_TARGET [имя]` | держится рядом с … |
| `OPERATE_MACHINERY` | работает на станке |
| `OPERATE_STORAGE` | разносит по складам |
| `MAN_A_TURRET_PLAYER_JOB` | дежурит у турели |
| `FIND_AND_RESCUE_IF_THERES_BEDS`, `FIND_BED_AND_PUT_IN` | относит раненых в кровати |
| `USE_BED_ORDER` | лежит в кровати |
| `PICKUP_INTRUDERS`, `TAKE_INTRUDER_OUTSIDE` | выносит чужаков с базы |
| `chase` | преследует противника |
| `taunt` | провоцирует противника на себя |
| `ranged` | ведёт дальний бой |
| `non_combat` | не вступает в бой |
| `weapon_back`, `weapon_hip` | основное оружие, второе оружие |
| `body`, `shirt`, `head`, `legs`, `boots` | броня корпуса, рубашка, шлем, поножи, обувь |
| `left_arm`, `right_arm`, `left_leg`, `right_leg` | левая рука, правая рука, левая нога, правая нога |
| `hunger_raw` (сытость с дробной частью) | Не выводится; голод упоминается, только когда он влияет на вывод |
| `blood` (кровь) | целым числом |
| `Мк II 55`, `Мейто 100`, `ур. 60` | грейд предмета (Мк II, Мейто); уровень — только когда он важен для вывода |
| `state_code` 0 / 1 / 2 | мёртв / жив / в плену |
| `calc_status` | Не выводится; значения `calc_*` при `verified` приводятся как характеристики предмета, иначе — «данных нет» |
| Имена колонок `tables/*.csv` | Не выводятся; приводится смысл значения |
