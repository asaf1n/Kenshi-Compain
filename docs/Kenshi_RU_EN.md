# Kenshi — справочник RU / EN

Названия из материалов кампании «Хроники Хот Лон» и данных игры: русское название по Steam-локализации, английский оригинал; пользовательские имена сохраняются. Наличие названия не означает посещения места, найма персонажа или получения предмета. Основные таблицы извлечены из документов кампании до дня 112 и с поздней историей полностью не сверялись; разделы «окно характеристик и навыков» и «Коды и поля выгрузки» сверены отдельно. Текущие факты кампании устанавливаются по действующим источникам.

## Источники и обозначения

- **Х** — [Хронология](../Campaign/Хроники%20Хот%20Лон/Kenshi_Хронология.md).
- **Б** — [Архетипы и билды](../Campaign/Хроники%20Хот%20Лон/Kenshi_Архетипы_и_билды.md).

Ссылки вида «Х, гл. 9» и «Б, §4» относятся к редакции этих документов от 30 октября 2026 года; номера разделов текущих версий могут отличаться.

В основных таблицах приведены только явно записанные в Х или Б пары. Падеж и число русских названий приведены к словарной форме; написание сохранено, включая необычные формы из источников. Х и Б ссылаются на установленный `locale/ru_RU/gamedata.po`; при подготовке этого извлечения файл локализации заново не сверялся. Следовательно, подтверждение пары здесь означает её наличие в актуальном документе проекта, а не отдельную проверку установленной игры.

**Не подтверждено** — в прочитанных документах нет явной пары RU / EN. Знак **—** в таком случае означает пробел в данных, а не отсутствие английского названия. **Не идентифицировано** — не установлен конкретный игровой объект. Предполагаемые переводы вместо пропусков не подставляются.

## Коды и поля выгрузки

Подписи для текста вместо сырых значений `published/`. Подписи описательные: строки локализации игры здесь — только навыки и характеристики (раздел выше). Код, которого нет в таблице, описывается словами по смыслу, без вывода самого кода.

| Код или поле | Подпись в тексте |
|---|---|
| `ps:…` | Не выводится; только при совпадении имён — в скобках после имени |
| `Безымянные_N` | Не выводится; отряд называется именем, которое дал игрок |
| `in_region` | в регионе … |
| `in_location` | в тексте модели — с названием локации в нужном падеже («в Скуине»); в генерируемых материалах (карта, сводки) — «в локации: Скуин» |
| `near_location` | в тексте модели — «в окрестностях Деревни Серодёров» (с расстоянием, если оно важно); в генерируемых материалах — «рядом с локацией: Деревня Серодёров» |
| `kind`: `town` / `village` / `outpost` / `ruins` | город / деревня / аванпост / руины |
| `kind`: `military` / `slave_camp` / `prison` / `poi` | военная база / лагерь рабов / тюрьма / особое место |
| `JOB_MEDIC` | лечит раненых |
| `JOB_REPAIR_ROBOT` | чинит скелетов и протезы |
| `BODYGUARD [имя]` | охраняет … |
| `STAY_CLOSE_TO_TARGET [имя]` | держится рядом с … |
| `OPERATE_MACHINERY` | работает на станке |
| `OPERATE_STORAGE` | разносит по складам |
| `MAN_A_TURRET_PLAYER_JOB` | дежурит у турели |
| `FIND_AND_RESCUE_IF_THERES_BEDS`, `FIND_BED_AND_PUT_IN` | относит раненых в кровати |
| `USE_BED_ORDER` | лежит в кровати |
