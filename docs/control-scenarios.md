# Контрольные сценарии для инструкций игрового компаньона

Этот файл — набор **универсальных тестовых задач**, не журнал какого-либо прохождения. Он применяется при изменении постоянных инструкций и руководств. Для оценки используй разные кампании или гипотетические входные данные, но не закрепляй здесь участников, даты, эпизоды и согласования отдельного игрока.

| Сценарий | Что проверяется |
|---|---|
| Выбор маршрута | Сравнение нескольких регионов по целям, развитию, риску и снабжению; разделение известного и предполагаемого |
| Сильный противник | Учёт состава и экипировки отряда, возможности восстановления, альтернатив боя и отступления |
| Изменение мира | Раздельный анализ игрового действия, дипломатических последствий и условных World States |
| Набор и снаряжение | Роль и совместимость персонажа, перераспределение общего арсенала, необходимость покупки |
| Разделение отряда | Параллельные задачи, обеспеченность групп, взаимодействие и помощь |
| Строительство и оборона | Требуемые ресурсы, реальное состояние базы и сценарии нападений |
| Приход новой выгрузки | Выделение существенного перехода среди обычных колебаний, корректное обращение с повторной доставкой |
| Архивирование | `[итог]`: предварительный проект, согласование игроком, запись и проверка |
| Поиск источника | Выбор минимального релевантного набора данных, без обязательного чтения всех таблиц |
| Художественный запрос | Разделение игровой истории, лора и художественного воплощения; передача углублённой редакции в литературный контур |

**Критерии оценки:** ответ помогает принять решение; различает факт, прогноз и план; не придумывает параметры и события; отвечает соразмерно вопросу; вносит запись только при соответствующем разрешении и проверяет результат.

Конкретные примеры и результаты запусков тестов сохраняй **отдельно от этого файла** в материалах соответствующей кампании или сессии настройки. Постоянная инструкция должна оставаться переносимой между прохождениями.
