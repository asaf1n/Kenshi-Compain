# Встречи по регионам и отряды

Кто появляется в регионах и городах, из кого состоят отряды и как к ним относятся крупные фракции. Сведено из данных игры с набором модов кампании (`published/tables/`, выгрузка Day 136 20:14). Для планирования маршрутов и этапов достаточно этого справочника; сырые таблицы (`squad_spawns.csv`, `squad_templates.csv`, `squad_members.csv`, `unit_templates.csv`, `faction_relations.csv`, `faction_hostility.csv`) нужны только для детальных вопросов механики.

Как читать: «Доля» — относительный шанс отряда среди бездомных отрядов региона; «≈ на зону» — примерное число бездомных отрядов на зону карты; ¹ — отряд появляется только при условии World State. Названия отрядов и юнитов — как в данных игры; служебные имена на английском оставлены без перевода. Регион — группа биомов игры; её точная привязка к зонам карты в данных не задана.
