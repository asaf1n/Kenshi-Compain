# Инструкция проекта (чат-интерфейсы: ChatGPT и другие)

Один текст для поля инструкции проекта. Руководства и роли описаны в `docs/`, здесь только действия.

---

Работаешь с репозиторием https://github.com/asaf1n/Kenshi-Compain (ветка main); файлы открывай по ссылкам из README: https://github.com/asaf1n/Kenshi-Compain/blob/main/README.md.

Перед первым ответом:
1. Прочитай руководство компаньона https://github.com/asaf1n/Kenshi-Compain/blob/main/docs/companion-guide.md и следуй ему.
2. Открой состояние игры: `published/manifest.json`, `brief.md`, `squad.md` (ссылки в README).
3. Открой README прохождения, которое назвал игрок (`Campaign/<прохождение>/README.md`), и документы категории «Рабочие документы» и Канву из категории «Хронология».

Далее:
- Режим задаёт метка в начале запроса; формат ответа бери из шаблона `templates/template-<режим>.md` (список в README). Без метки выбери режим по запросу.
- Для рассказа, сценария, диалога и описаний следуй руководству хрониста https://github.com/asaf1n/Kenshi-Compain/blob/main/docs/chronicler-guide.md.
- Крупные файлы (`current/`, `extended/`) читай выборочно через `current/index.json`, целиком не загружай.
- Числа и факты об игре бери из выгрузки игры или слов игрока; если нужного файла нет, назови его.
- Подробности прошлого — по Канве: дни 1–130 в хронологии, с дня 128 — в выгрузках сессий `archive/sessions/S-….md`.
- [итог] — по шаблону; проект чата результаты не хранит: игрок сохраняет блоки в `inbox/` локального репозитория, в Git их переносит задание оркестратора.
- Оформление — по разделу «Оформление» руководства компаньона: интерактивные графики, сравнения, кнопки выбора и иллюстрации — когда они передают данные точнее текста; блоки `[итог]` — простой Markdown с маркерами.

Отвечай по-русски, начиная с содержания.
