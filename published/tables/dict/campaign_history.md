# Словарь колонок таблицы campaign_history.csv

- Назначение: Динамика казны и численности отряда по дням
- Ключ сортировки: day
- Ключи соединения: day

## Нормативные примечания

- Фиксация состояния на момент последнего сохранённого снимка каждого игрового дня (день, время, баланс казны, численность отряда).

## Колонки

| Колонка | Описание / Тип |
|---|---|
| `day` | Игровой день |
| `game_time` | Игровое время снимка |
| `cats` | Баланс казны игрока |
| `squad_size` | Численность отряда |
