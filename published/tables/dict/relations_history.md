# Словарь колонок таблицы relations_history.csv

- Назначение: История дипломатических отношений с фракциями
- Ключ сортировки: day, faction_sid
- Ключи соединения: faction_sid

## Нормативные примечания

- Длинный формат истории дипломатических отношений: строка создается при первом упоминании фракции и при каждом последующем изменении отношения.

## Колонки

| Колонка | Описание / Тип |
|---|---|
| `day` | Игровой день |
| `faction_sid` | sid фракции |
| `faction_name` | Название фракции |
| `relation` | Значение отношений |
