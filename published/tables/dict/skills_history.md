# Словарь колонок таблицы skills_history.csv

- Назначение: История изменения уровней навыков и атрибутов
- Ключ сортировки: day, character_id, skill
- Ключи соединения: character_id

## Нормативные примечания

- Дельта-трекинг целочисленных уровней по цепочке дней: охватывает 4 базовых атрибута (ATTRIBUTES) и 33 навыка (SKILL_LABELS). При первом появлении персонажа фиксируются все непустые атрибуты и навыки, далее строка создается только при изменении целой части уровня.

## Колонки

| Колонка | Описание / Тип |
|---|---|
| `day` | Игровой день |
| `character_id` | Идентификатор персонажа |
| `character_name` | Имя персонажа |
| `skill` | Название навыка или атрибута |
| `level` | Целочисленный уровень |
