Загрузить полный выпуск

По умолчанию загружается текущий published/ через HTTP-сервер из корня репозитория. Для ручной загрузки выберите manifest.json, world_reference.json, locations.json и, если указан в манифесте, location_registry.json. Можно добавить locations_progress.json. Замена выпуска другой кампании, ветки или снимка требует подтверждения.
