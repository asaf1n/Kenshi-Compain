# Шаблон режима: [сверка]

## Назначение

**Сервисная операция только по явному запросу игрока** для проверки существенных противоречий между постоянным каноном `Campaign/<кампания>/`, текущим сессионным контекстом и фактическими данными `published/`. При необходимости — согласование точечных редакторских правок. Не является обязательной стадией `[ход]` → `[итог]`.

## Правила

1. **Новый сейв не является триггером.** Обычные изменения `game_time`, здоровья, денег, навыков, позиций или кадров обрабатываются в `[ход]`, не в `[сверка]`.
2. **Только существенные различия.** Читай в GitHub только затронутые `Kenshi_Текущая_арка.md`, `Kenshi_Архетипы_и_билды.md`, `Kenshi_Канва.md` и необходимые фактические источники. Не копируй в канон числовой снимок игры, доступный в `published/`.
3. **Watermark — граница сохранённой истории**, а не последний обработанный сейв. Не сдвигай `Сверено до:` в `[сверка]`; он обновляется после проверки и подтверждённого сохранения завершённого `S-YYYYMMDD-n` через `[итог]`. При откате или смене `branch_id` обозначай неопределённость, не выбирая каноническую ветку за игрока.
4. **Не изменяй утверждённые решения и архив** без прямого указания игрока.
5. **Минимальные правки:** максимум 1–2 уточняющих вопроса при необходимости. Показывай diff или заменяемые фрагменты только затронутых документов. Не пересоздавай целые файлы и не выводи неизменённые.
6. **Без закрытия сессии:** не создавай `S-...`, не добавляй строку Канвы и не используй шаблон `[итог]` для сервисного пакета. Применяй правки в GitHub только после отдельного разрешения игрока.

## Минимальный ответ

```markdown
### Сверка: <предмет>
**Факты и источники:** <сейв / текущий чат / постоянный документ>
**Противоречие:** <если есть>
**Предлагаемая правка:** <файл и точный фрагмент либо «не требуется»>
**Уточнить:** <не более двух вопросов при необходимости>
**Запись:** не выполнена / выполнена по разрешению (коммит)
```

Если существенных противоречий нет, сообщи, что `Campaign/` актуален и правки не требуются.
