# Ориентир режима [сверка]

Сервисная проверка существенных противоречий между подтверждённой историей, текущими решениями и фактической игровой публикацией. Выполняется только по запросу игрока; очередной `[ход]` не запускает её автоматически.

**Источники:** относящиеся к предмету Хронология, текущая арка, билды, закрытые сессии, свидетельства игрока, `published/`. Выбирай объём проверки по природе расхождения; изменение оперативных чисел не равнозначно противоречию с каноном.

Сопоставляй источник и временную границу каждого утверждения. Не заменяй сохранённую историю предположением и не смешивай ветки игры. Выноси на уточнение только вопросы, от которых зависит существенная правка, без лимита или обязательного количества вопросов.

Форму ответа выбирай по задаче: объяснение конфликта, конкретная правка, diff, перечень недостающих свидетельств. Не пересоздавай документы без необходимости. `Сверено до:` меняется при подтверждённом архивном закрытии, а не в результате очередной сверки.

Правки в GitHub выполняй лишь по разрешению игрока и после проверки актуального HEAD. `[сверка]` не создаёт новую игровую сессию.
