# Шаблон режима: [итог]

Режим `[итог]` закрывает сессию тремя результатами:

1. **Выгрузка сессии** — художественные тексты сессии без изменений и разбор сессии по решениям; хранится в истории прохождения под идентификатором сессии.
2. **Строка хронологии** — краткая заметка для Канвы со ссылкой на выгрузку.
3. **Правки рабочих документов** — новый текст Текущей арки и, при изменениях, Отряда.

Вызывается в конце сессии и для промежуточной фиксации; повторный вызов выпускает полную обновлённую версию с тем же идентификатором. Где хранятся результаты и как они сохраняются, задаёт инструкция проекта.

## Правила

1. **Идентификаторы.** Сессия — `S-YYYYMMDD-n` (дата реального дня и порядковый номер). Решение — `D-nnnn`, сквозная нумерация по всем выгрузкам сессий прохождения: следующий номер — последний использованный плюс один.
2. **Художественные тексты — без изменений.** В выгрузку входят все художественные тексты, написанные в сессии (`[хроника]`, сцены, рассказы, описания), в порядке появления, дословно. Правка, сокращение и переписывание отсутствуют; удаляются только элементы интерфейса чата вокруг текста.
3. **Разбор по решениям — минимальная правка.** Ход сессии излагается по решениям игрока. Очистка:
   - удаляются форматирование чата (заголовки ответов, интерактивные элементы, повторы), технические диалоги (сбор источников, ошибки, служебные проверки) и предложения, к которым игрок не вернулся;
   - сохраняются рассуждения компаньона по существу, варианты, выбор и исход;
   - слова игрока приводятся дословно.
4. **Статус решения.** `approved` — только по словам игрока; `rejected` — с причиной; `proposed` — предложение без ответа игрока; `superseded→D-nnnn` — заменено.
5. **Числа** — из выгрузки игры или слов игрока; рядом с числом в скобках — источник, если он неочевиден.
6. **Пустой раздел** помечается «—» и остаётся в выгрузке.
7. **Простой Markdown.** Результаты выдаются блоками с маркерами `=== … ===`, без интерактивных элементов и изображений: по маркерам результаты сохраняются и переносятся в Git.
8. **Неизменность.** Выгрузка, сохранённая после начала следующей сессии, не меняется; уточнения вносятся разделом «Исправления» следующей выгрузки.

## Пакет для Git

Пакет переносит результаты в репозиторий. Состав пакета задаёт инструкция проекта; формат:

````markdown
=== ПАКЕТ ДЛЯ GIT · Day N HH:MM · сессии <S-первая> — <S-последняя> ===
=== ПРАВКИ: <имя документа> ===
<полный текст документа>
=== ВЫГРУЗКА S-… ===
<выгрузка сессии целиком>
=== ФАЙЛ: <путь в репозитории> ===
<произведение или раздел повести>
=== КОНЕЦ ===
````

Блоки `ПРАВКИ`, `ВЫГРУЗКА` и `ФАЙЛ` повторяются по числу документов, сессий и файлов.
