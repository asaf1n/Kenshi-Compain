# Проверка записи GitHub

Дата: 2026-11-07.

Назначение: проверить создание нового файла отдельным коммитом в `main` без изменения игровых материалов кампании.

Состояние: файл создан и затем изменён вторым самостоятельным коммитом.

## Проверка последовательности

1. Первый коммит создал файл.
2. Второй коммит обновил содержимое того же файла.
3. Оба изменения записаны непосредственно в удалённую ветку `main` через GitHub API.
